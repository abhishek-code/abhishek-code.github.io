public class SalesServiceAgentConnector {
    @InvocableMethod(label='Get Unified Customer Context' description='Retrieves unified sales and service metrics for agent grounding')
    public static List<CustomerContextResult> getCustomerContext(List<String> accountIds) {
        List<CustomerContextResult> results = new List<CustomerContextResult>();
        for (String accId : accountIds) {
            results.add(new CustomerContextResult(accId, 'Active Enterprise SLA', 450000.00, 0));
        }
        return results;
    }
    
    public class CustomerContextResult {
        @InvocableVariable public String accountId;
        @InvocableVariable public String slaTier;
        @InvocableVariable public Decimal openPipeline;
        @InvocableVariable public Integer openCriticalCases;
        public CustomerContextResult(String a, String s, Decimal p, Integer c) {
            this.accountId = a; this.slaTier = s; this.openPipeline = p; this.openCriticalCases = c;
        }
    }
}

Security Precaution

Always avoid assigning generic System Administrator profiles to integration users. Require dedicated Integration Licenses with explicit Field-Level Security (FLS) boundaries.

@RestResource(urlMapping='/v1/headless/secureService/*')
global with sharing class SecureHeadlessService {
    @HttpPost
    global static ResponseWrapper executeSecureAction(String recordId) {
        if (!Schema.sObjectType.Account.isAccessible()) {
            RestContext.response.statusCode = 403;
            return new ResponseWrapper('ERROR', 'Access Denied');
        }
        return new ResponseWrapper('SUCCESS', 'Operation Completed');
    }
    global class ResponseWrapper {
        public String status;
        public String message;
        public ResponseWrapper(String s, String m) { this.status = s; this.message = m; }
    }
}

Headless Experience Layer: Custom Types, Widgets & Supported Channels

Constructing rich agentic UI using Custom Lightning Types (LightningTypeBundle), LWC Overrides, and HXL Declarative Widgets (UiWidgetBundle).

Headless Experience Layer: Custom Types, Widgets & Supported Channels →

Step-by-Step Implementation Flow

  • Step 1: Define Apex Data Model
    Create an Apex class with @AuraEnabled fields representing the custom UI payload.
  • Step 2: Declare Custom Lightning Type
    Define schema.json inside a LightningTypeBundle to map Apex structures.
  • Step 3: Configure Channel LWC Overrides
    Place renderer.json inside channel subfolders (e.g., lightningDesktopGenAi) for in-app Salesforce experiences.
  • Step 4: Configure Cross-Platform HXL Widgets
    Define root-level renderer.json and UiWidgetBundle artifacts to render declarative cards in external MCP clients like ChatGPT, Claude, and Slack.
